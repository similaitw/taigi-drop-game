# 台語闖關大挑戰

給現場閩南語互動擺攤用的網頁小遊戲合集，部署在 Vercel。

| 網址 | 內容 |
|---|---|
| `/` | 遊戲選單：六關入口與玩法說明 |
| `/drop` | 台語接接樂：接住掉落的台語詞 |
| `/duel` | 搶答對決：雙人對戰，平板平放可面對面 |
| `/memory` | 翻牌記憶：台語與華語配對 |
| `/proverb` | 俗語接龍：選出俗語下半句（題目在 `proverbs.json`） |
| `/speak` | 講台語挑戰：看華語講台語，工作人員判斷 |
| `/bingo` | 台語賓果：主持人抽詞念台語，玩家用局號拿卡 |
| `/admin` | 題庫管理（密碼登入，雲端儲存、版本備份） |

訪客到攤位找關主闖關，過關時畫面會出現大大的「🎉 過關！」給關主確認。
題庫存在 Vercel Blob，透過 `/api/words` 讀取；管理密碼設在環境變數 `ADMIN_PASSWORD`。
